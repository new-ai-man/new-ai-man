# 实验 #1：自媒体选题自动化

- **状态：** 🔬 验证中
- **启动：** 2026-07-31
- **目标客户：** 内容创作者（小红书/抖音/公众号）
- **收入：** $0

## 假设

创作者愿意为「每周自动推送的领域热点选题」付费。

## 为什么值得做

1. 选题是创作者日常刚需，付费意愿明确
2. MVP 门槛低，可快速验证
3. 案例即内容，天然适配 build in public

## 方法

1. 接 1-2 个真实创作者（先从我自己的号开始）
2. 交付物：自动抓取目标领域热点 → AI 生成选题 + 标题 → 每周推送
3. 全程记录：投入小时 / 成本 / 客户反馈

## 技术方案（待定）

- 热点抓取：目标平台公开数据 / RSS / 第三方 API
- 选题生成：LLM API（按领域定制 prompt）
- 推送：邮件 / 飞书 / 微信群机器人
- 部署：定时任务（GitHub Actions / 云函数）

## 成功标准

- [ ] 有真实创作者愿意持续付费
- [ ] 或明确反馈"有用，继续"

## 下一步

- [ ] 找到第一个真实用户
